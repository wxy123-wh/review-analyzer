# 项目启动与账号指南

## 1. 🚀 快速启动（推荐）

本项目已实现**全自动打包与启动**。前端代码会自动打包到后端应用中，只需运行一个脚本即可启动所有服务（含NLP服务）。

### 启动步骤

1. **一键构建与打包**
   ```powershell
   ./build-release.ps1
   ```
   > 该脚本会自动：编译前端、移动静态资源、打包后端JAR、准备NLP环境。

2. **启动应用**
   ```powershell
   cd release
   ./start.ps1
   ```
   > 该脚本会自动：在后台启动NLP服务、启动Java后端服务。

启动成功后，访问：[http://localhost:8081](http://localhost:8081)

## 3. 🛠️ 开发模式（仅研发人员）

如果你需要**修改代码**并实时预览（Hot Reload），才需要分别启动各个服务。**普通用户或演示运行无需使用此模式。**

| 服务 | 目录 | 启动命令 | 说明 |
| :--- | :--- | :--- | :--- |
| **NLP 服务** | `nlp_service/` | `python main.py` | 提供聚类算法支持 (Port: 8000) |
| **后端** | `backend/` | `./mvnw.cmd spring-boot:run` | 提供API接口 (Port: 8081) |
| **前端** | `frontend/` | `npm run dev` | 提供Vue界面 (Port: 5173) |

> **注意**：开发模式下，前端运行在 5173 端口，后端在 8081 端口。

---

## 4. 常见问题

- **数据库配置**：首次运行前，请确保本地 MySQL 已启动，并且已导入 `backend/src/main/resources/schema.sql`。
- **端口冲突**：脚本默认使用 8081 (Web) 和 8000 (NLP) 端口，请确保未被占用。
